# Changelog

## v1.0.0

- Initial unified package extracted from the calorie and hakkes-workspace forks.
- Includes scope amendments, requirement amendments (renamed from the hakkes `amendment`),
  successor-run budget carryover, phase-binding and author-identity recovery, capsule author rotation,
  slicing, parallel batches, and the ship-analyze tooling.
- Fixes: `**` glob segments, bounded check execution, sanitized gate logs, capsule fingerprint includes
  run exclusions, non-git scope checks, narrower exception handling, and install-depth-independent root
  discovery.
- Adds `install.sh` and `Makefile` for pinned snapshot installs from git tags.
